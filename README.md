**Flower Login Page

This is my simple Flower Login Page project.

I made this project using HTML, CSS and JavaScript. I tried to create a clean and attractive login page with a flower theme.

* Features
Login form
Username and password fields
Submit button
Flower-themed design
Simple and clean layout
JavaScript validation
Success alert for correct login details
Error alert for wrong username or password
